# 汤姆猫跑酷 - 多主题赛季系统完整落地实施计划

## 背景与目标
在 `E:/zcode Project/` 创建一个 **可直接打包运行** 的 Unity 2022.3 LTS / URP 工程，实现设计文档中的完整赛季系统，包含绚丽自然美观的 UI 界面。

## 实施里程碑（9 个工作日）

### M1 - 工程骨架与核心目录结构
- Unity 2022.3 LTS + URP + Addressables + TextMeshPro + DOTween + UniTask + VContainer 初始化
- 目录结构：`Assets/_Project/{Seasons,Core,UI,Common,Tests}`
- Assembly Definition 划分（Runtime/Editor/Tests）
- Git 忽略、EditorConfig、代码规范

### M2 - 核心运行时系统
- `SeasonManager`：赛季状态机、时间同步、配置热更
- `LevelStreamer`：基于距离的增量实例化/回收、对象池
- `ProceduralLevelGenerator`：Chunk 语法树 + 马尔可夫链生成 Segment → 离线烘焙 LevelData
- `ThemeProfile` / `SeasonConfig` / `BattlePassTable` ScriptableObject
- 10 个白模 Chunk 预制体（Jump/Slide/Attack/Coin/Powerup/Hazard 等）

### M3 - 通行证与活动框架
- `BattlePassSystem`：双轨奖励、XP 曲线、付费验证接口
- `EventScheduler`：MiniEvent 基类 + 2 个示例活动
- MockServer 单例模拟服务端数据

### M4 - Addressables 热更管线
- Group 划分：Season_Core / Season_Phase_N / Shared_Base
- 构建脚本、Catalog 版本控制
- `ContentUpdater`：启动/切前台增量下载、进度 UI、失败重试
- 本地 CDN 模拟器

### M5 - **绚丽 UI 系统** ⭐ 核心亮点
设计语言：**「霓虹赛博 × 有机流体」**
- MVVM 框架 + UniRx/Observable
- 6 大核心界面：SeasonHub、BattlePassView、LevelHUD、RewardPopup、EventPanel、LoadingScreen
- UIShaderLib：SDF 圆角、流体噪波、色差、全息扫描、边缘发光
- UIParticleSystem：UI 空间粒子
- MotionLibrary：弹性缓动、跟随延迟、磁吸对齐、磨砂背景模糊
- ThemeColorPalette：每主题一套 ScriptableObject 色板

### M6 - 自动化测试与 QA 管线
- PlayMode/EditMode 测试覆盖核心逻辑
- AutoRunnerBot 跑酷 AI 验证
- 性能基准断言

### M7 - CI/CD 与交付包
- GitHub Actions：Windows + WebGL 构建
- 版本号自动递增、Changelog 生成
- 交付：可执行文件 + 启动指南
